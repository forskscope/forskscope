# RFC directory

Design decisions — alternatives weighed, questions closed — are recorded as
RFCs, not in this guide. See the
[RFC directory](https://github.com/forskscope/forskscope/tree/main/rfcs) for
the full list, organized by lifecycle state (proposed, accepted, done, archive).
[RFC-000](https://github.com/forskscope/forskscope/blob/main/rfcs/done/000-rfc-lifecycle-policy.md)
governs that lifecycle.
