Compare and merge files and folders, side by side.

ForskScope is a desktop app for Linux, macOS and Windows. Open two files or two folders, see what changed, and apply changes from one side to the other. Everything runs on your computer.

Download Read the guide Free and open source, Apache-2.0

Why ForskScope

ForskScope began as one more option among the GUI tools for comparing and merging files on Linux, where its author found the choices too few.

  • Your files stay on your computer.No accounts, no uploads, no telemetry. The only network request is the one you make by clicking Check for updates.
  • Start from folders, not only files.The Explorer shows two directory trees side by side, marks each file as identical, different or on one side only, and opens any pair you pick.
  • It does not claim more than it checked.A file is marked identical only after its contents were compared. When only the sizes match, it says so, and Verify reads every byte to find out.
  • Spreadsheets too..xlsx workbooks are compared sheet by sheet and cell by cell, read-only, with rows lined up by content where that shows fewer changes.
  • Keyboard first.Move between changes, apply them, search, and switch panes without the mouse.
  • Works with Git.Use it as git difftool and git mergetool. The guide shows the settings.
  • Carry it with you.On Windows and Linux, ForskScope is a single program file with no installer. Put a folder named forskscope-data beside it, and it keeps everything of its own in that folder, not in your home folder. That suits a USB drive, or a desktop where your home folder is read-only. Or start it with --private, and it keeps nothing after it closes.

Two folders at a glance

Pick a folder for each side. Each file says how it compares, and in the Aligned layout files with the same name share a row. Choose one on each side and press Compare.

Download

Every release is on the GitHub releases page. Pick the file for your system below.

Linux

forskscope-v…-linux-x86_64.tar.gz

Extract it and run ./forskscope.

Built on Ubuntu, so it needs a glibc at least as new as that build's. It also runs on Arch Linux. Other distributions have not been tested.

Arch Linux: install forskscope from the AUR with your AUR helper.

macOS

forskscope-v…-macos-aarch64.dmg

For Apple silicon Macs, macOS 13 or later.

The app is not signed with an Apple Developer ID and not notarized, so macOS refuses to open it the first time. Right-click the app and choose Open, or run:

xattr -d com.apple.quarantine /Applications/ForskScope.app

Windows

forskscope-v…-windows-x64.zip

Extract it and run forskscope.exe.

ForskScope is also on the Microsoft Store, but that listing is not yet updated with each release. For the newest version, use the zip.

Tested on Windows 11. It needs the WebView2 runtime, which Windows 11 includes. Nothing else to install.

Want it portable? See Running portably.
